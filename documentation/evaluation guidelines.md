Media Content Relevance Evaluation Guidelines

Purpose

These guidelines define how media content is evaluated based on the user's query, content type, language, topic, and relevance.

Media Types

Music
Video
Book
Podcast
News
App

Search Intent

Informational

The user wants to learn or find information.

Navigational

The user wants to find a specific website, application, or content page.

Transactional

The user wants to buy, download, subscribe, or perform an action.

Comparison

The user wants to compare different options.

Topic Match

Yes

The content directly matches the requested topic.

Partially

The content is related but does not completely match the requested topic.

No

The content does not match the requested topic.

Relevance Ratings

Highly Relevant

The content directly matches the user's query and intent.

Relevant

The content is closely related and useful but may not completely satisfy the query.

Partially Relevant

The content has some connection to the query but does not fully satisfy the user's intent.

Not Relevant

The content does not meaningfully match the user's query or intent.

Evaluation Process

1. Read the user's query.
2. Understand the user's intent.
3. Identify the media type.
4. Review the content title and available information.
5. Check the language and topic.
6. Determine whether the content matches the query.
7. Assign a relevance rating.
8. Explain the reason for the rating.
9. Record the evaluation in the dataset.

Evaluation Principles

Evaluate content based on the user's query and intent.

Consider topic, media type, language, and usefulness.

Use consistent evaluation criteria.

Provide a clear reason for every evaluation.
